# Study Buddy

## Overview
Study Buddy is a real-time collaborative web platform designed for students and teachers to connect, learn, and solve academic problems together. It combines community-driven Q&A, subject-based group discussions, and live peer-to-peer video interactions to enhance collaborative learning and exam preparation.

The platform enables students to get help instantly, join subject-specific communities, and interact with peers or educators through both text and video-based communication.

---

## Objective
The goal of Study Buddy is to build a unified learning network where:
- Students can get instant academic help
- Teachers can actively engage with learners
- Peer-to-peer learning is encouraged
- Knowledge sharing is fast, structured, and interactive

---

## Key Features

### 1. Community-Based Learning
- Subject-wise groups (Physics, Mathematics, Chemistry, etc.)
- Public posts for asking and answering academic questions
- Teacher and student participation in discussions

### 2. Real-Time Video Matching
- OmeTV-style random video pairing for academic discussions
- Option to skip or switch to another user
- Rating and review system for interaction quality

### 3. Chat System
- One-to-one messaging
- Group chats for specific subjects or topics
- Lightweight and fast communication layer

### 4. Role-Based System
- Students can ask questions and join discussions
- Teachers can provide structured guidance and mentorship

---

## Tech Stack
- TypeScript (Frontend / Core logic)
- Rust (Performance-critical backend services)
- Go (Scalable backend APIs / real-time services)
- JavaScript (Client-side logic)
- HTML & CSS (UI layer)

---

## System Design Highlights
- Real-time communication architecture for chat and video sessions
- Modular backend design separating streaming, chat, and community systems
- Scalable microservice-oriented structure (Go + Rust services)
- Event-driven updates for live interactions

---

## Use Cases
- Exam preparation and doubt solving
- Peer learning and discussion groups
- Teacher-student interaction outside classrooms
- Collaborative study sessions across subjects

---

## Key Idea
Study Buddy is designed to transform isolated studying into a connected learning experience by combining social networking, real-time communication, and structured academic communities.

---

## Summary
A real-time academic collaboration platform that connects students and teachers through community posts, subject-based groups, and live video interactions to improve collaborative learning and exam preparation.
